# Support

Use GitHub Discussions for setup questions and GitHub Issues for reproducible defects.

Before opening an issue:

1. Reproduce the problem in fixture mode.
2. Run `npm test`, `npm run typecheck`, and `npm run qa`.
3. Remove credentials, participant information, recordings, transcripts, and private URLs from logs.
4. Include the Node.js version, operating system, and minimal reproduction steps.

This community project does not provide an SLA or emergency operational support.
