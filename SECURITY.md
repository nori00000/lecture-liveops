# Security Policy

## Supported version

Security fixes are provided for the latest release on the default branch.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue containing exploit details, credentials, participant data, or deployment URLs.

Include:

- Affected component and version
- Reproduction steps using synthetic data
- Security impact
- Suggested mitigation, if known

You should receive an initial acknowledgement within seven days. Disclosure timing will be coordinated after a fix is available.

## Deployment responsibilities

Operators are responsible for authentication configuration, database isolation, notification consent, retention policy, access reviews, secret rotation, and deletion requests. Never use fixture credentials or sample configuration in production.
