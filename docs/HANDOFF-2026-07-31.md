두 적대 검증(Codex 코드 리뷰 + critic)이 찾음. 파일:라인 확정됨.

### C1 (코어 보안, 두 트랙 공통) 참가자 그룹 위조
- **파일**: `lib/action/handlers/delib.ts:319` `submitStatement`, `:332` `assertStatementScope` 호출, `:297` 함수 정의
- **결함**: 참가자 저자는 `trusted.participantId`로 고정하지만 `input.groupId`는 클라이언트 값을 그대로 넘긴다. `assertStatementScope`(297~)는 그룹의 **세션 일치만** 확인하고 참가자의 실제 membership과 대조하지 않는다. → 참가자가 `/api/action` 직접 호출로 자기 소속이 아닌 같은 세션 임의 groupId에 `visibility='group'` 발언 삽입 가능. 그룹별 익명성·토론 경계 붕괴.
- **수정**: `envelope.actor.role === 'participant'`이면 `input.groupId` 무시, `delibGroups.findMembershipByParticipant(ctx, participantId)`의 조회값만 사용. input.groupId가 trusted membership과 다르면 403.
- **테스트**: 참가자가 타 그룹 groupId로 제출 시 거부.

### C2 (트랙 B 프라이버시) 전사 동의 우회
- **파일**: `app/api/data/dialogue/live/route.ts:24,27,78` / `projector/route.ts:24,27,79`
- **결함**: `transcripts.listSources()`/`listSegmentsBySourceIds()`를 먼저 읽고 `readRecordingConsent()`는 배지용으로만 씀. → `recordingConsent=false`거나 `transcript_sources.consent_confirmed_at=null`이어도 전사 원문이 화면에 노출. 동의 게이트가 ingest만 막고 read를 안 막음.
- **수정**: `recording.active`(recordingConsent) + source별 `consent_confirmed_at`을 전사 read 선행 조건으로. 동의 없으면 `transcriptSegments=[]` 고정. live·projector 공통 helper.

### C3 (트랙 B 프라이버시) projector가 그룹 발언을 방 전체 노출
- **파일**: `app/api/data/dialogue/projector/route.ts:25`(`visibleOnly:true`), `:47`(previewSegments), `:55`(`text: s.body`)
- **결함**: `visibleOnly:true`는 moderation만 거르고 `visibility='group'` 발언까지 가져와 방 전체 화면(Room Mirror)에 원문 노출.
- **수정**: projector payload는 `visibility='public'` 발언만(또는 퍼실 승인 artifact만). group visibility 원문 제외.

### C4 (트랙 B 거버넌스, MAJOR) 승인 게이트 부재 + 단일 발언 지목
- **파일**: `lib/dialogue/nudges.ts:89`(participant가 `projector_safe`까지 포함), `lib/dialogue/stateMap.ts`의 `isAssertion()`(부분 문자열 매칭)
- **결함**: `DIALOGUE-LENS-PRODUCT.md` Must-Never #2("진행자 승인 없이 참가자 전체 화면 표시 금지")를 위반 — 승인 게이트가 코드에 없고, 단일 짧은 발언이 nudge로 승격돼 participant 폰에 바로 뜸(역추적 가능).
- **수정**: (a) participant/projector nudge는 최소 2개 이상 독립 segment + 최소 길이 조건. 단일 segment는 `operator_only`로 강등. (b) `nudges.ts:89`에서 participant visibility의 `projector_safe` 포함 제거(`participant_safe`만). (c) 참가자·프로젝터 노출은 기본 off, operator 명시 활성화 시만.

### C5/C6 (MINOR)
- C5 `live/route.ts` 전사 미연결 시 `index*12000`ms **가짜 타임스탬프**로 실시간 대화 위장 → 실제 created_at 쓰거나 "제출 순서" 명시.
