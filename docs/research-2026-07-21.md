## 1. 레포 판정 (Codex·Claude 독립 분석 수렴)

**"운영 shell 재사용 + 숙의 core 신규 구축 하이브리드"** — 리브랜딩 수준으로는 불가.

재사용 가치 높음:
- 단일 `/api/action` 엔벨로프(권한 매트릭스+감사원장) — 단, 멱등성은 in-memory `globalThis` Map이라 serverless 인스턴스 간 미보장 (critic 발견). 투표 중복방지의 실체는 DB unique 제약으로 신규 구축해야 함
- access_key→httpOnly 쿠키 무설치 참가자 온보딩, RLS 3중 방어, seat_layouts(테이블 단위) 그룹 보드 원형, md/html/xlsx export (**PDF는 스텁** — critic 발견)

신규 구축 필수: `participants`(현재 익명 쿠키뿐 — 중복투표 방지·클러스터링 전제 결여), `breakout_groups`/`rounds`, `statements`/`statement_votes`, 의견 지도 스냅샷, 시각화(차트 의존성 0)

즉시 수정 대상: `0002_rls_policies.sql:205` 정책명 공백(SQL 문법 오류 — external_archives RLS 미적용 가능성), `accessKeys.ts:63-80` O(n) bcrypt 전수 스캔 + `demo-hash-`/`endsWith` 인증 우회 경로, `next.config.mjs:11` eslint 빌드 무시

실시간 제약: "실시간"=SWR 2~3초 폴링. Vercel serverless(icn1)라 WS/SSE 불가 → 대규모 라이브 의견 지도는 아키텍처 재설계 또는 전사·실시간 전용 별도 서버 필요.

레포 신뢰성: 공개 레포는 3커밋 덤프(개발 이력 없음), README/REQUIREMENTS 빈 템플릿. 실질은 테스트 30파일.

## 4. 적대 크리틱 최종 판정: **RECONSIDER**

HIGH 공격 (살아남음):
1. **사업 타당성 공백**: 누구에게 파는가·왜 Pol.is/Decidim/Mentimeter/Slido가 아닌가·make-vs-buy 비교가 전무. "자가 컨설팅 도구라면 Mentimeter 구독이 압도적으로 쌈"
2. **일정 2~3배 과소추정**: 8~11주(부업)는 달력상 5~7개월. 특히 Phase 3(전사→PKM)는 다인 화자·소음 한국어 STT WER 30~50% 현실에서 단독 6~10주
3. **차별점 붕괴**: 20~30명 소규모에서 PCA 클러스터링은 통계적으로 무의미 → "opinion landscape"가 타깃 규모에서 작동 안 함 (100명+ 한정 기능)
4. **도메인 해악 과소평가**: 교회·학교에서 파벌 가시화·소수자 낙인·권위자의 결과 오남용. 소규모 익명은 사실상 익명이 아님. UI 반창고가 아닌 **거버넌스 설계** 필요
5. **누락**: 폰 없는 참가자(노인·아동) 오프라인 병행, 접근성(색각·시각약자), 운영자 교육, 모더레이션 악용, 미성년자 PIPA 동의, **kill 기준 부재**

RECONSIDER→PROCEED 최소 조건:
1. 유료 고객 3인 인터뷰 **또는** 본인 컨설팅 3회에서 Mentimeter+클로바노트 조합으로 가짜문 테스트 → 지불의사·니즈 실증
